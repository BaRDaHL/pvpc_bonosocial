# Tarjeta PVPC + Bono Social / PVPC + Bono Social card

**Español.** La tarjeta que se instala con la integración (`custom_components/pvpc_bonosocial/frontend/pvpc-bono-social-card.js`) es un paquete generado a partir de `src/` con Lit 3.2.1 y esbuild 0.24.2 (versiones fijadas en `package-lock.json`). Para regenerarla:

**English.** The card shipped with the integration (`custom_components/pvpc_bonosocial/frontend/pvpc-bono-social-card.js`) is a bundle built from `src/` with Lit 3.2.1 and esbuild 0.24.2 (versions pinned in `package-lock.json`). To rebuild it:

```sh
npm ci
npm run build
```
